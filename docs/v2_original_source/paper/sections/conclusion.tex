\section{Conclusion}
SloshBot-RL packages two reproducible native simulation experiments with explicit scientific boundaries. The enlarged trajectory remains unresolved under its complete acceptance criteria, including the privileged V4 and existing residual PPO. Keyboard command replay demonstrates stable traversal for one registered route and ROM failure for another, while a single modal-feedback transfer does not establish superiority. The contribution is an auditable experimental platform, matched data and preserved negative evidence. Neither successful rendering nor duration completion establishes full-task, hardware or resolved-fluid validity. Further control or physics research requires a separately authorized protocol; this release launches no new training.
